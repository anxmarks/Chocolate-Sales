# 🍫 Chocolate Sales Analysis - Data Science & BI
This project performs a comprehensive analysis of a chocolate sales database, integrating data processing with **Python** and creating an executive dashboard in **Tableau**. 
The main objective is to extract strategic insights related to revenue performance, product efficiency, and regional sales distribution.

## 🚀 Overview
The project simulates a real-world business scenario, where raw data is cleaned, transformed, and analyzed to support strategic decision-making.

The workflow includes:
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Business-driven metric creation
* Insight generation
* Executive dashboard development


The original data file is publicly available on [Kaggle](https://www.kaggle.com/datasets/saidaminsaidaxmadov/chocolate-sales).


## 🛠️ Technologies Used
* **Python 3.13.0**: Data processing and cleaning.
* `Pandas`: DataFrame manipulation and statistical calculations.
* `Matplotlib/Seaborn`: Graph prototyping and exploratory analysis.
* **Google Gemini**: Used as a co-pilot for strategic planning, defining business problems, and Prompt Engineering to generate analytical insights.
* **Tableau Public**: Interactive dashboard development.
* **Git/GitHub**: Version control and documentation.

## 📊 Dashboard
This project includes an interactive dashboard developed in Tableau Public, designed to provide a strategic overview of chocolate sales performance between 2022 and 2024.

Although this was my first Tableau project, the dashboard was built with a strong focus on business insights and executive usability.

🔗 Access the Dashboard:
[View on Tableau Public](https://public.tableau.com/app/profile/ana.marks/viz/chocolate_17708360642380/Overview?publish=yes)

## 🎯 Business Value
This dashboard transforms raw sales data into an executive decision-support tool by:
* Centralizing KPIs
* Highlighting growth patterns
* Identifying top-performing products
* Showing geographic revenue distribution
* Applying the Pareto principle for strategic focus
